IP (Internet Protocol)

Cada dispositivo em uma rede possui um IP.

Esse é seu identificador na rede, assim como temos nosso CPF.

Cada servidor, site, computador possui o seu “CPF”.



“Muito se fala em: tenho seu IP e sei sua localização, mas o que isso quer dizer?”

Calma.

Esse IP não é o que aparece quando você executa ipconfig no Windows ou ip a no Linux.

Esse é o seu IP privado.

Tanto é que o meu IP e o seu podem até ser iguais agora.

Para que a rede funcione na prática, o IP que precisa ser diferente é o IP público.



IP privado, IP público e NAT

É nessa hora que entram o roteador e o provedor.

É o provedor que fornece o seu endereço IP público e, através do NAT (Network Address Translation),

ocorre a tradução do seu IP privado para o IP público.

Como usuário comum em uma residência, você normalmente possui um IP dinâmico.

Ele altera de tempos em tempos ou quando o roteador é reiniciado.

Por isso, em um dia você pode estar com um IP e, no outro, seu vizinho pode estar usando esse mesmo IP.



“Mas então eu posso fazer maldade na internet e resetar o roteador que não vão conseguir me rastrear?”

Se fosse assim, a internet seria uma verdadeira bagunça.

É aí que entra o CGNAT, que já atua no provedor.

Ele é responsável por esse “rodízio” de IPs.
